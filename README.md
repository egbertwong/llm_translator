# Refinery

Refinery is a minimal desktop translation app that focuses on speed, clarity, and everyday usability.

## Features
- Fast translation with a clean, focused UI
- Customizable prompts and LLM settings
- Local history and preferences
- Light and dark themes

## Architecture
Clean architecture with MVVM and dependency injection.

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Package (Electron Forge)
```bash
npm run make
```

Outputs are written to `out/`.

## Configuration
Open Settings in the app to configure the translation service, prompts, and appearance.
